Kurz gesagt

Die Demo braucht keine Anmeldung und schickt nichts von dem, was du eingibst, an einen Server. Was du anlegst oder änderst, ändert nur die Beispieldaten in deinem Browser – nach dem Neuladen ist alles wieder wie vorher.

Hosting bei GitHub Pages

Die Seite liegt bei GitHub Pages (GitHub, Inc., USA, ein Unternehmen von Microsoft). Beim Aufruf verarbeitet GitHub technisch nötige Daten, vor allem deine IP-Adresse, zum Beispiel in Server-Protokollen für die Sicherheit. Auf diese Daten hat 4inOne keinen Zugriff. Mehr dazu in der Datenschutzerklärung von GitHub.

Was dein Browser speichert

  • Keine Cookies, kein Tracking, keine Analyse-Dienste.
  • Keine fremden Schriften oder Dienste: Alle Dateien kommen von GitHub Pages.
  • Ein paar Ansichtseinstellungen merkt sich dein Browser lokal, etwa Liste oder Kacheln in der Einkaufsliste, die Gruppierung der Aufgaben und ausgeblendete Hinweise in Finanzen. Sie werden nicht übertragen; du löschst sie mit den Website-Daten in deinem Browser.
  • Nach einem Ladefehler setzt die Seite kurz einen technischen Merker, damit sie höchstens einmal von selbst neu lädt. Er verschwindet, wenn du den Tab schließt.

Kontakt und deine Rechte

Fragen zum Datenschutz an die Person, die dir den Link geschickt hat, oder über GitHub (Rückmeldungen zu 4inOne). Für die Server-Protokolle ist GitHub zuständig; dort kannst du Auskunft, Berichtigung und Löschung verlangen. Außerdem darfst du dich bei einer Datenschutz-Aufsichtsbehörde beschweren.

Später, mit Konten
